# My Chatbot Project 🐢

Hey! How's it going? This is my chatbot project. For now, it doesn't have a name yet.

## A few things to clarify

This is still a test version, and there are quite a few bugs. I simply want to show the progress I make while learning how to build a chatbot from scratch.

As I mentioned, the program has some issues. For example, **false positives**. Let's say you tell the chatbot, *"Hey, I don't want you to tell me a joke."* It might still tell you a joke. You'll understand what I mean as you explore the project.

Another problem is how the program handles input. For example, if you ask *"What time is it?"* or say *"Hey, how are you?"*, the program might respond with *"Unknown"* because of punctuation or other characters it doesn't handle correctly yet.

## Why am I publishing it now?

I want to share my program and show what I'm working on. It might not be great yet, but keep in mind that this is a test version. The idea is to improve it day by day and keep saving each stage of its development in this repository.

I want to look back and see how much I've learned, how far I've come, and how much I've improved.

And you might be wondering: **What have I learned so far?**

I've learned how to use new functions and simplify my code instead of creating a huge staircase of `if/elif` statements.

I've also improved my logical thinking a lot by asking myself questions like, *"Why doesn't this work?"* or *"Why does it behave this way?"*

## How I use AI while learning

Yes, I did use AI, but not by simply saying, *"Give me the code"* or *"Solve this for me."*

I use it more like a tutor. When I get stuck on a problem, it helps me understand what's going on instead of spending ten hours desperately searching through documentation and Google without knowing where to start.

That said, I'm not a fan of using AI to generate an entire program for you. In my opinion, you miss out on learning new things that way. Sometimes, AI can also give you results that aren't what you wanted.

But anyway, if you're reading this, **you're a legend! 🐐 Trust the process — and trust my process.**

I hope you have a wonderful day, and thanks for checking out my project! Feel free to share your thoughts, suggest things I could add, or even collaborate if you're interested. I'd really appreciate it. :3
